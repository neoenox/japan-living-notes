# 配布物の記録（どのファイルを売ったか）

Payhipは差し替え時に旧ファイルを保持しない。そのため、**配布したファイルの控えはこのリポジトリが唯一**になる。差し替えのたびに、ここに1行足す。

- 照合方法: `sha256sum <ファイル>`（Windows: `certutil -hashfile <ファイル> SHA256`）の値が、Payhipからダウンロードしたファイルと一致するか確認する。
- 版は本文の `Edition 2026` と対応する。本文を変えたら版を上げるか、日付で区別する。

## 差し替えのたびにやること

1. 生成 → `python tools/check_pdf.py <PDF> <ページ数>` で確認。
2. この表に、日付・ページ数・サイズ・SHA256 を追記する。
3. 差し替え後、Payhipから**ダウンロードしてSHA256を照合**する（一致しなければ差し替えは失敗している）。
