# 監視依頼: YouTube案の再検討タイミング

2026-11-18 に「YouTubeはいまはやらない」と判断した。その判断を見直す条件だけを監視する依頼。
**監視するのは依頼された側（Muse）。再検討の判断と実作業は pi が行う。**

## 判断の要約（2026-11-18）

- 結論: いまはYouTubeをやらない。
- 理由:
  - $9の商品に対して動画のコストが見合わない（登録者0からの試算で月$1〜13、動画1本5〜10時間）
  - Pinterest の Day 7 / Day 30 を計測する前に変数を増やすと、何が効いたか分からなくなる
  - 動画は公開後に訂正が効かない（保証会社・礼金・更新などの制度記述）
  - YouTube の「日本で賃貸」は無料情報が飽和していて、見た人は$9を払わない
- 先にやる順番: Pinterest計測の完了 → ブログ記事の公開 → 必要なら縦60秒Shorts 3本で需要検証のみ

## 監視する数字

取得できたものだけ記録する。**推測で埋めない。取れなければ「未取得」と書く。**

| 対象 | 場所 | 期限 |
|---|---|---|
| Pinterest インプレッション / 保存 / アウトバウンドクリック | 管理画面 → `marketing/launch-baseline-2026-11-18.md` の表に追記 | Day 7 = 2026-11-25、Day 30 = 2026-12-18 |
| Payhip 購入件数 / 商品ビュー（第1弾・第2弾） | ダッシュボード → 同じ表に追記 | 同上 |
| ブログ記事 `marketing/blog-initial-costs.md` が公開されたか（公開URLの有無） | 公開先 | 随時 |

## 「頃合い」の条件（どれか1つ成立したら再検討）

1. Payhip の購入が累計10件以上
2. Day 30 の Pinterest アウトバウンドクリックが30以上
3. $29前後のセット商品、または相談メニューが用意できた
4. ブログ記事が公開され、公開から30日経過した

## 成立していないとき

- 期限前、条件未達、数字が取れない → 静かに終了する。通知しない
- 途中経過を残す場合も、数字と日付だけ。評価や提案は書かない

## 報告の形（条件成立時のみ）

- 3行以内。事実の数字だけ。取得できなかった項目は「未取得」
- 最後にこの一文だけ添える: **「YouTube案の再検討を pi に依頼する」**
- 動画の企画、構成案、サムネ案、台本は書かない（pi の担当）

## pi に戻ってきたときの作業

1. `marketing/launch-baseline-2026-11-18.md` の数字を読む
2. 条件3が成立しているなら、$29前後のセット商品を先に組む（動画より先）
3. 動画をやるなら、ガイド1冊＝長尺1本（8〜12分、章立てがそのまま台本）。チャンネルの定期更新は前提にしない
4. `docs/TODO.md` の「集客・販売」に判断と結果を追記する
